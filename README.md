# Raspored – samostalna verzija (bez Claudea, bez računa)

Radi bez interneta. Sve se sprema samo na uređaju na kojem se koristi.
Barbin raspored turnusa (1. godina, 2026./27.) već je unutra.

## Na računalu
Dvaput klikni `index.html`. Otvara se u pregledniku i radi odmah.

## Na mobitelu (preporučeno): besplatno preko GitHub Pages
1. Na github.com napravi novi repozitorij, npr. `raspored` (Public).
2. *Add file → Upload files* → povuci SVE datoteke iz ove mape (index.html, manifest.webmanifest, sw.js, ikone) → *Commit*.
3. *Settings → Pages → Branch: main, / (root) → Save*.
4. Za minutu-dvije link je: `https://TVOJE-IME.github.io/raspored/`
5. Barbi otvori link na mobitelu i doda ikonu:
   - iPhone (Safari): Dijeli → **Dodaj na početni zaslon**
   - Android (Chrome): ⋮ → **Instaliraj aplikaciju** / Dodaj na početni zaslon
6. Nakon prvog otvaranja radi i bez interneta.

## Korištenje
- **＋ Novi** → odaberi novi Excel s faksa → provjeri → Spremi. Aplikacija pokaže što je novo i što je otkazano.
- **Satnica** → upiši uobičajene sate po vrsti nastave.
- **Verzije → Spremi kopiju**: povremeno spremi kopiju (npr. na Google Drive). Ako se obrišu podaci preglednika ili promijeni mobitel, **Vrati iz kopije** sve vraća.

## Napomene
- Čita Excel (.xlsx), CSV i tablicu kopiranu iz Excela. PDF i fotografije ne čita (to radi samo verzija na Claudeu).
- Podaci se ne dijele između uređaja: što Barbi spremi na mobitelu, vidi samo ona na tom mobitelu.
- Fontovi se učitavaju s Google Fonts kad ima interneta; bez interneta koristi se sistemski font.
